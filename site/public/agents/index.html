The part no remote solves

Your agent dies when the lid closes.

Both first-party remotes are clear about where the work happens: on your machine. Which means the machine has to stay awake — and macOS sleeps a MacBook the moment the lid closes, unless a monitor and keyboard are plugged in. The refactor stops mid-file, and your phone is a window into a dead session. The usual fix is a hardware dummy HDMI plug.

reminal fixes it in software. Flip on closed-lid mode and leave: it disables clamshell sleep and spins up a virtual display the moment the Mac goes headless, so the agent keeps working and every window keeps streaming. Toggle it off and everything is undone. Keep /remote-control if you like it — reminal is what keeps the machine alive underneath it.

Ninety seconds

Start a session, close the lid, walk away.

  1. Install. curl -fsSL https://reminal.app/install.sh | sh — macOS, Linux or Windows.
  2. Run reminal in the terminal where your agent lives (or wrap it: reminal claude). It prints a session ID, a PIN and a QR code.
  3. Scan the QR with your phone. That browser tab is now a real terminal on your machine — and the Apps menu streams any window next to it. Close the lid; nothing stops.

Questions

The ones that come up.

How do I keep Claude Code or Codex running when I close my MacBook's lid?

macOS sleeps a MacBook when the lid closes unless a monitor and keyboard are attached — which kills any agent session running on it. reminal's closed-lid mode disables clamshell sleep and spins up a virtual display the moment the Mac goes headless, so the agent keeps working and every window keeps streaming into your browser. No dummy HDMI plug. Toggle it off and everything is undone.

Does Claude Code's /remote-control work with Codex or pi?

No. Each vendor's remote steers only its own agent. reminal streams the terminal and the windows themselves, so anything that runs in a terminal — pi, aider, opencode, a plain build script — is reachable from any browser.

Can I watch several agents at once?

Yes. reminal machines is one live view of every machine you own — every session, what's running, who's watching. Attach to whichever needs input, from the CLI or the browser.

Does my session pass through a vendor's cloud?

Sessions are end-to-end encrypted with AES-256-GCM under a fresh key per run; the relay routes ciphertext it cannot read and can't brute-force the PIN offline. There is no account, and the relay is open source — self-host it on Cloudflare in a few minutes. The privacy policy shows how to verify this yourself.

What does it cost?

The CLI is free and open source under AGPL-3.0, including the relay. A hosted tier — managed relay, permanent machine names — is coming.
