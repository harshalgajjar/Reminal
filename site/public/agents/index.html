For AI coding agents

Your agents can run for hours. Give them a home.

Claude Code can chew on a refactor for an hour. Codex can work a queue overnight. Run them that way and they stop being chats — they become resident processes, and a resident process needs three things: a machine that never sleeps, a view you can glance at, and a hand that can reach in when it stalls. reminal is that home — every agent, terminal and window, live in any browser, with the lid shut.

The part no remote solves

Your agent dies when the lid closes.

Both first-party remotes are clear about where the work happens: on your machine. Which means the machine has to stay awake — and macOS sleeps a MacBook the moment the lid closes, unless a monitor and keyboard are plugged in. The refactor stops mid-file, and your phone is a window into a dead session. The usual fix is a hardware dummy HDMI plug.

reminal fixes it in software. Flip on closed-lid mode and leave: it disables clamshell sleep and spins up a virtual display the moment the Mac goes headless, so the agent keeps working and every window keeps streaming. Toggle it off and everything is undone. Keep /remote-control if you like it — reminal is what keeps the machine alive underneath it.

Agent-agnostic

One view of every agent you run.

Vendor remotes stop at their own agent. reminal streams the terminal and the windows themselves, so it doesn't care what's running in them.

Claude Code

/remote-control shows you the conversation. reminal adds the other five windows: the dev server it just broke, the diff in your editor, the test suite tailing in the next pane, the browser it's poking at. Watch the agent and the blast radius.

Codex CLI

Codex pairing lives in the ChatGPT app, signed in. reminal needs no app and no account — run reminal, scan the QR, and any browser on any device is a full terminal on that machine.

pi · aider · opencode · anything

No first-party remote exists for these at all. If it runs in a terminal, reminal streams it — true colour, touch selection, find-in-scrollback, reconnect from another city with the shell exactly where you left it.

The whole fleet

Claude Code on the MacBook, Codex on the Linux box, a build on the Mini — one live view of every machine, every session, what's running and who's watching. Attach, spawn or kill from the CLI or the browser.

An agent can use the same door. Hand a session ID and PIN to an agent and it connects like any other viewer — triaging an incident on one box while it patches another, with you watching both in the same browser. Since v3.5.0 it doesn't even need the PIN: see below.

Agent bus

Your agents can see each other.

Claude Code on the laptop, Codex on the build box. Same problem, no shared anything — every vendor's answer is subagents inside its own product, which doesn't help when the agents come from different vendors. reminal makes the terminal the bus: one MCP server, nine tools, and every session on every machine you own becomes something an agent can read and answer.

$ 
reminal integrate

Registers the MCP server with whichever agent CLIs you already have — Claude Code, Codex CLI, Cursor CLI, Gemini CLI, OpenCode, Antigravity CLI, Amp.

claude-code — studio-maclive

  1. list_sessions

    3 machines · 7 live sessions — studio-mac, aws-eu-1, mini-01

  2. search_sessions pattern: "FAIL|Traceback"

    aws-eu-1 · agent-7 — pytest: 2 failed, 118 passed

  3. read_transcript session: "agent-7"

    …AssertionError: expected 200, got 502 — it has been retrying the same request for nine minutes

  4. send_keys session: "agent-7", keys: "the 502 is the proxy in front of you, not your handler — check X-Forwarded-Proto", enter: true

    Typed into agent-7 on aws-eu-1. It carries on from there.

list_sessions

Every live terminal on every machine you own — name, working directory, title, who's watching it, how long it's been idle. No PINs, ever, in the output.

search_sessions

One regex across session names, paths, titles and live scrollback, on every enrolled machine at once. Find the box where the build is actually failing.

read_transcript

Pull a session's terminal as plain text, ANSI stripped — so one agent can read what another is stuck on instead of asking you to copy it across. It doesn't attach a viewer.

send_keys

Type into a session's PTY, across machines. The other side needs no integration at all: it's just a terminal, and it never knows anything is watching.

They don't have to be the same agent, or from the same vendor. Claude Code can read a Codex session and answer it; a Gemini CLI on your Mac mini can watch a build the laptop started. There is no protocol for anyone to adopt, because the bus is the terminal — if it runs in a PTY, it can be read and typed into.

send_keys types real keystrokes into a real shell. It only reaches machines you enrolled yourself, everything it does is visible live in the viewer — and it's still a tool that can type Ctrl+C into your terminal. Treat it with the respect that deserves.

Window notes

And an agent can raise a hand.

An agent that gets stuck has exactly one channel today: a line of text in a terminal you aren't looking at. reminal gives it another — a badge pinned to the window the question is actually about. The browser it's driving, the editor it's editing, the simulator it can't get past. Colour carries the meaning, and red is the only one that moves.

Google Chrome2 notes
Which test card should I use?

Every 4242 number is declined on this account. I've paused before placing a real order.

claude-code · 2m
Replaying the cart fixture

No action needed — this one just says what it's doing.

claude-code · now
attention — blocked on you. Pulses. working — mid-task, no action wanted info — worth seeing done — nothing owed

list_windows

Every window on screen with the id the other tools take, its app and its bounds. Ids are ephemeral on purpose — they die with the window, so an agent looks them up fresh.

add_note

Pin a badge on one window: a short title, a line of detail, a status. Pass the same note_id again and it updates in place — working becomes done instead of a pile of stale notes.

read_replies

What you did about them. handback means you pressed Done and it's the agent's turn again; dismiss means you cleared it; closed means the window went away. Delivered once, then forgotten.

remove_note · clear_notes

Take one note off, or the whole badge. Notes live exactly as long as their window, so there is never anything left to tidy up — nothing is written to disk.

It's a handshake, not a notification. The agent posts attention and stops; you see a red dot on the actual window, from your desk or your phone; you fix the thing and press Done; the agent's next read_replies returns a handback and it picks the work back up. That's the loop a long-running agent has been missing — a way to ask, and a way to be answered, without you tailing a log.

Window notes need the desktop badge helper, which is macOS today. The four session tools above work on macOS, Linux and Windows alike.

Ninety seconds

Start a session, close the lid, walk away.

  1. Install. curl -fsSL https://reminal.app/install.sh | sh — macOS, Linux or Windows.
  2. Run reminal in the terminal where your agent lives (or wrap it: reminal claude). It prints a session ID, a PIN and a QR code.
  3. Scan the QR with your phone. That browser tab is now a real terminal on your machine — and the Apps menu streams any window next to it. Close the lid; nothing stops.

Questions

The ones that come up.

How do I keep Claude Code or Codex running when I close my MacBook's lid?

macOS sleeps a MacBook when the lid closes unless a monitor and keyboard are attached — which kills any agent session running on it. reminal's closed-lid mode disables clamshell sleep and spins up a virtual display the moment the Mac goes headless, so the agent keeps working and every window keeps streaming into your browser. No dummy HDMI plug. Toggle it off and everything is undone.

Does Claude Code's /remote-control work with Codex or pi?

No. Each vendor's remote steers only its own agent. reminal streams the terminal and the windows themselves, so anything that runs in a terminal — pi, aider, opencode, a plain build script — is reachable from any browser.

Can one AI agent talk to another one on a different machine?

Yes. reminal integrate registers reminal's MCP server with the agent CLIs you have installed — Claude Code, Codex, Cursor, Gemini, OpenCode, Antigravity, Amp. An agent can then call list_sessions to see every terminal on every machine you own, search_sessions to regex their live scrollback, read_transcript to read one, and send_keys to type into it. The two agents don't have to come from the same vendor, and the far side needs no integration — it's just a terminal.

How does an agent tell me it's blocked without me watching the terminal?

It calls add_note with status attention, which pins a red badge to the window the question is about — the browser it's driving, the editor it's editing. The badge shows on the desktop and in every viewer, so it reaches your phone. Press Done and the agent's next read_replies returns a handback, and it picks the work back up. Window notes need the desktop badge helper, which is macOS today.

Can I watch several agents at once?

Yes. reminal machines is one live view of every machine you own — every session, what's running, who's watching. Attach to whichever needs input, from the CLI or the browser.

Does my session pass through a vendor's cloud?

Sessions are end-to-end encrypted with AES-256-GCM under a fresh key per run; the relay routes ciphertext it cannot read and can't brute-force the PIN offline. There is no account, and the relay is open source — self-host it on Cloudflare in a few minutes. The privacy policy shows how to verify this yourself.

What does it cost?

The CLI is free and open source under AGPL-3.0, including the relay. A hosted tier — managed relay, permanent machine names — is coming.
