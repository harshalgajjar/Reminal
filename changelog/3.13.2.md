# 3.13.2

Improved
- An agent you share a session with — using just its link or PIN — can now
  **read the terminal, not only type into it**. Until now a shared agent could
  send keystrokes but couldn't see the output unless the session was running on
  one of your own machines, so it was effectively working blind. Now the same
  link that lets it type also lets it read what's on screen, so it can follow
  along and actually help.
