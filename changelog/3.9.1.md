# 3.9.1

Fixes
- `reminal new` now works with no internet, like `reminal list` and `reminal
  attach` already did. It used to hang and time out when the machine was
  offline, even though the new session was up and reachable on the same
  computer — now it returns right away and you can attach to it locally.
- Attaching to a session on this computer no longer gets stuck on
  "Reconnecting… are you offline?" after that session is killed. When the
  session you're attached to ends and there's no network to fall back to, the
  viewer now says the session ended and exits, instead of retrying forever.
