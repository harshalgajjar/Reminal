# 3.22.15

Improved
- The note reminal keeps of why a session ended is now written the moment the session is over, so it is there even when the session is stopped while it is still tidying up. Files kept for a fault that turned out to hold nothing are removed once the session is gone.
- Ending a session with `reminal kill`, or by pressing Ctrl-] twice, is now immediate. It used to take two seconds.

Fixed
- The page that shows a session no longer loads anything from other sites. Everything it needs now comes with reminal, so it opens on networks that block those sites, and it no longer comes up blank when one of them is slow. If part of the page fails to load, it says so and asks you to reload.
- On Windows, a change of the system clock could make reminal lose track of which session a command was run in. It no longer depends on the clock for this.
