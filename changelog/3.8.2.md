# 3.8.2

Fixes
- The Host panel could keep showing an "Upgrade" button — offering the very
  version the machine was already on — after you updated it any way other than
  by pressing that button (from the command line, or when the machine updated
  itself). The version shown was already correct; only the leftover offer was
  wrong, and it cleared if you reopened the panel. It now clears itself the
  moment the machine reports its new version, so the button goes away on its own.
