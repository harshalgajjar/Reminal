# 3.7.0

New
- Your Machines list can now show each machine's live CPU and memory beside the
  battery, so you can tell at a glance whether there's room to start something on
  it. The reading comes from the machine itself, so a given machine starts
  showing it once that machine has updated to this version.

Improvements
- Your machines stay reachable when they're idle. An owned machine now shows up
  as online — and you can open a session on it — even when nothing is running on
  it, instead of dropping off the list the moment its last session closed. It
  runs as a small background helper that starts after you first use reminal on a
  machine and comes back on its own after a reboot.
