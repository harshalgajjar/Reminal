# 3.6.3

- The upgrade button is always there for a machine's owner, not only when the
  last background check happened to have noticed a release. Pressing it checks
  for real; a host already on the latest says so, and nothing is replaced or
  restarted. Spotting a new version yourself is now enough to act on it.
- Release notes no longer label the versions between yours and the newest
  "skipped". One upgrade lands on the newest and carries every release in
  between, so only the version you are running is marked.

Fixes
- Reverted 3.6.2's hourly update check. Polling harder was the wrong answer to
  "the button isn't there yet" — being able to check on demand is. Machines ask
  once a day again.
