# 3.22.12

Improved
- Tapping or clicking in a window you are viewing answers faster when the picture travels through reminal's relay. Many apps answer a tap in two steps: the button shows pressed, then the result appears a moment later. Only the first of those pictures was sent straight away, and the one with the result waited about a fifth of a second. Now the pictures that follow a tap are sent straight away too.
- On a Mac with many reminal sessions, the battery is now read once for the whole computer, as the CPU already is, and every session uses that one reading. Before, every session checked the battery on its own every ten seconds.

Fixed
- reminal again notices when Claude Code turns a sign-in away because the account belongs to a different organization than the computer allows. Claude Code 2.1.331 changed the words it says this with, and reminal no longer read them.
