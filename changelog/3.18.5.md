# 3.18.5

Fixed
- On a Mac, when the screen capture stops sending pictures, reminal now starts it again within seconds instead of staying on "Connecting…". If the new one sends nothing either, reminal keeps trying, waiting a little longer each time.
- On a Mac with the lid shut and no other screen plugged in, reminal now gives windows a screen to draw on, as it already did on a Mac with no screen at all.
- A window with no picture yet now says so after a few seconds, instead of showing "Connecting…" with no end. The message also mentions the two usual causes: the window is minimized, or Screen Recording is off for reminal on that Mac.
