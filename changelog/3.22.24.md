# 3.22.24

Improved
- When an upgrade brings a new hook for an agent you already set up (as 3.22.23 did for Qwen Code), reminal now adds it by itself, with no need to run `reminal integrate` again: as reminal starts, or, for a hook that only newer versions of an agent have, when that agent is next closed in a session. It takes effect the next time the agent starts. A hook of reminal you removed yourself is not put back.
