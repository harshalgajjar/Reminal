# 3.14.11

Fixed
- A session whose agent has quit no longer keeps the old agent's last
  state. Before, a "working" or "done" left behind by an agent that had
  exited stuck to the session until it timed out.
- An agent that has gone completely quiet for a minute and a half is no
  longer shown as working on the strength of its last hook alone.
- A question waiting at the bottom of the screen counts as needing you
  even when the agent's hooks said it was done, which is what Claude
  Code reports when it stops to ask you something.
- cursor-agent, and agents that run as plain node or python processes,
  are recognised as agents by what was launched rather than by the
  process name, so their sessions are read and listed as agents.
- Reading an agent's screen as text works on its normal screen too, not
  only when it has switched to a full-screen view.
- Release notes written as paragraphs show as paragraphs in What's new,
  instead of as a wall of capitals.
