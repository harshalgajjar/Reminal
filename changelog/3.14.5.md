# 3.14.5

New
- Your agents can now report a problem with reminal to you. When an agent
  hits something reminal got wrong — a tool that misbehaved, a transcript
  that looked off, keys that never landed — it can file a report with the
  `report_issue` tool instead of complaining into the void. Reports stay on
  that machine: `reminal issues` lists them, `reminal issues export` turns
  them into a bug report you can paste, and nothing is ever sent anywhere
  on its own.

Fixed
- Opening a session's terminal on your phone no longer flips its dot to
  "working" for a moment. Resizing the terminal made the program redraw,
  and the redraw looked like activity.
- An agent that merely *quoted* a "please log in" message — telling you
  what it saw on another screen — was shown as logged out itself, and its
  messages were held. Only an agent that actually says so is logged out now.
- Updates are checked before they are installed. A download is verified
  against its published digest, and a build that is not what it should be
  is never put in place.
