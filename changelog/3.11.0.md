# 3.11.0

Remote windows now feel like they're running on your own machine.

Improved
- **Controlling a remote window is instant now.** Clicks, scrolling, and typing
  go straight to the host instead of taking the long way around, so a window
  reacts the moment you touch it rather than a beat later. On Mac, clicking
  around inside a window no longer has that little hitch before each click lands.
- **Windows and Linux windows are far smoother — and hold up on slow
  connections.** They now stream as real video, the same way Mac windows already
  did, so instead of a heavy, choppy picture you get a smooth one that stays
  usable over a phone or a weak network. Every platform now gets the crisp,
  low-bandwidth mirror Macs have had.

Fixed
- A **done** session keeps its badge now. Previously, a while after a session
  went quiet, its "done" mark could just disappear — most noticeable on sessions
  that picked up state-reporting through the in-app upgrade. It now stays marked
  done until you give it something new to do.
- A session that's genuinely waiting on you no longer quietly downgrades itself
  to **done** after a minute. If an agent stopped to ask a question or for a
  permission, it keeps showing **needs you** until you actually answer.
