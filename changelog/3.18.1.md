# 3.18.1

Improved
- The tour now shows sleep, with the moon on each session, and Moments: the receipts, timelapses and memes Share can make from a session, with an example meme.
- Waking a session shows "Waking…" in the middle of the screen, the way "Connecting…" does.

Fixed
- A sleeping session picked from the session switcher now wakes, instead of trying to connect to a session that isn't running.
- Sleeping or waking a session on a computer with an older reminal now tells you to run `reminal upgrade` there, instead of an unclear error.
