# 3.21.1

Safety
- Voice now types what you say only into an agent it can tell is waiting for a message: one set up with `reminal integrate` that has reported in, and, for Claude Code, Qwen Code, Gemini CLI, OpenCode and Kilo, only while its input box is on screen. Elsewhere it says why and types nothing.

Improved
- Your agent answers out loud without asking you first. `reminal integrate` now allows reminal's speak tool, and only that tool, in Claude Code, Gemini CLI and Qwen Code. Run `reminal integrate` again to get this.
- Qwen Code can answer voice out loud: it now loads reminal's tools when it starts instead of hiding them until it searches for them.

Fixed
- On a device with no voice of its own, voice no longer goes quiet without a word. With Auto it switches to the natural voice; if you picked the device's voice, it says the device has none. Your agent is told a line was not heard instead of being told it was spoken.
