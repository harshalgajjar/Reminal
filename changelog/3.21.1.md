# 3.21.1

Safety
- Voice now types what you say only into an agent it can tell is waiting for a message: one set up with `reminal integrate` that has reported in, or one whose input box it can see. Elsewhere it says why and types nothing.

Fixed
- On a device with no voice of its own, voice no longer goes quiet without a word. With Auto it switches to the natural voice; if you picked the device's voice, it says the device has none. Your agent is told a line was not heard instead of being told it was spoken.
