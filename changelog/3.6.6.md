# 3.6.6

- Keyboard shortcuts now reach the window you're driving. Copy, paste, undo,
  select-all — any ⌘ or Ctrl combination is sent to the machine you're
  controlling instead of being caught by your own browser, so a window on a
  machine far away behaves like one that's right in front of you.
- Windows apps show their real icons in the launcher now, so the app you're
  after is easy to spot at a glance — the same way your Mac and Linux apps
  already do.

Fixes
- On a machine still waiting on a permission prompt, the list of apps and open
  windows could quietly stop answering. It now gives up on a step that's stuck
  and keeps going, so the machine stays responsive instead of going silent.
