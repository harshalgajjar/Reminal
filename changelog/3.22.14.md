# 3.22.14

Fixed
- The browser tools now work in Chrome for Testing, the copy of Chrome that browser automation downloads. reminal did not count it as a browser before.
- On Windows, reminal no longer brings up the Windows Firewall question ("allow public and private networks to access this app?") the first time a window or the desktop is viewed. The question stayed on top, and while it was up clicks sent into a viewed window did nothing.
- `reminal integrate` no longer waits for ever on a coding agent whose own command does not answer. After 45 seconds it says which one did not answer and carries on with the rest.
