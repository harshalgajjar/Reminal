# 3.6.0

- Upgrade a machine from the browser. When a newer version is out, the Host
  panel offers "Upgrade & restart": it installs the release and hot-restarts
  every session on that host, keeping the shells and whatever is running in
  them.
- Read what you are getting first. "What's new" shows the notes for every
  version you are behind, not just the newest, so catching up on several
  releases is one read.
- Only owners can do it. The request carries a signature from a device enrolled
  as an owner of that machine, and it is checked before anything runs — hiding
  the button is not the control. Someone you shared a session with by PIN cannot
  upgrade the host they are visiting.
- Two people pressing at once upgrade the machine once. Whoever gets there first
  installs; anyone else watches the same steps instead of starting a second
  install on top of the first.

Fixes
- A machine whose sessions all run in the background never learned that a new
  version existed, so the upgrade was never offered on exactly the always-on
  hosts it is meant for.
- A failed upgrade now says what went wrong and leaves the host on its current
  version with every session untouched, rather than a progress bar that never
  finishes.
