# 3.6.2

Fixes
- A machine now notices a new release within the hour rather than within the
  day. The background check that feeds the Host panel deferred to a cache the
  startup prompt only refreshes every 24 hours, so a release published this
  morning could stay invisible until tomorrow — and an upgrade cannot be
  offered for a version the machine has never heard of. A failed check leaves
  the previous answer in place, so a brief network problem no longer makes the
  button disappear.
