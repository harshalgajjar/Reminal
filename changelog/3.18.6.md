# 3.18.6

Improved
- reminal now notices more of the work an agent leaves running in the background: Claude Code's monitors, workflows, MCP tasks and teammates, Gemini CLI's background processes, Qwen Code's background agents and Antigravity's background work. Before, it only counted background shells and subagents.
- `reminal list` shows that background work next to each session, for example "done · 1 shell · 2 monitors".
- `reminal sleep` now names any background work it would end, as it already did for shells and subagents.
- In the viewer, the alert dropdowns now say what each choice means, for example "Busy: CPU use above 80%". They look the same in every browser, and on a phone the list opens as a sheet from the bottom.
