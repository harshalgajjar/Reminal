# 3.12.1

Fixed
- The swipe-up session list now shows which sessions need you without opening
  anything. It used to refresh only while the Machines screen was open, so the
  state pills in the quick switcher could be stale until you opened a session —
  now the list keeps itself current on its own, and refreshes the moment you
  swipe it up.
- On Windows, your coding agents report their state again. The command reminal
  set up for them had a Windows path the agent's shell mangled, so it silently
  failed and no working / needs-you / done ever came through. It's written in a
  form the shell accepts now. Re-run `reminal integrate` on Windows to pick it up.
- On Linux Wayland machines, "View full desktop" now actually opens the screen.
  It was being blocked by the very note that explains Wayland's limits ("per-window
  control isn't supported here") — even though the full-desktop view works
  perfectly well on Wayland. The button now opens your desktop, and that note
  stays as a heads-up rather than standing in the way.
