# 3.6.9

Fixes
- When you're typing into a window and reach for the command bar — Paste, a
  snippet, one of the key buttons, or the path from a file you just uploaded —
  the text now goes into the window you're typing into. Before, Paste (and the
  rest) dropped into the terminal behind the window and pulled your keyboard
  shut, so the one thing you wanted to paste never reached the window. The whole
  bar now follows your focus: whatever the keyboard is aimed at is where the
  input lands.
