# 3.22.9

Added
- A new switch in the reminal button in your browser: `Type passwords and send sign-in forms`. It is off unless you switch it on.
- While it is off, nothing changes: an agent is refused at a password field and paused in a sign-in form. It is now told that this is your switch, so it can ask you.
- While it is on, agents in your reminal sessions can type into password fields and send sign-in forms in this browser.
- A typed password is never shown back or kept. The agent's result, the button's panel and the history page say only that a password was typed, and on which site.
- Payment fields are still never typed into, and a CAPTCHA still waits for you, whatever this switch says.
- `Resume` for a session you stopped. Its row in the button's panel now shows as stopped, with `Resume` beside it. Resume lets that same session use the browser again, with its tabs back in their group. The agent is not restarted.
- For browsers an administrator manages: the browser's policy can set the starting value of the passwords switch too. Your own switch always wins.

Improved
- When you stop a session, the agent is told that only you can allow it again, and where.
