# 3.13.7

Improved
- **Update every machine you own in one command.** `reminal upgrade
  --all-owned-machines` brings your whole fleet to the latest version. Machines
  already up to date are left alone, and anything offline is reported rather than
  quietly missed — so you can see what it reached and what it didn't. Point it at
  a single box with `--machine <name>`.
- `reminal restart` now takes the same targets, so you can restart the sessions
  on another machine without going and opening a terminal there. Your shells and
  whatever is running inside them come back: a restart moves reminal underneath
  them, it doesn't close them.
