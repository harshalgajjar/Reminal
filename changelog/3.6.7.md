# 3.6.7

- Windows apps show their real icons in the launcher now. The earlier attempt
  quietly fell back to a letter tile on some PCs; icons are read straight from
  Windows this time, so the app you want is easy to spot at a glance — the same
  way your Mac and Linux apps already do.

Fixes
- The Host panel could say "could not check" and "could not reach the release
  notes" for a stretch, then sort itself out. That was GitHub rate-limiting the
  machine during a busy hour. Both the update check and the release notes now
  read from a route that doesn't have that limit, so the panel just shows you
  what's new and whether there's an update — every time.
