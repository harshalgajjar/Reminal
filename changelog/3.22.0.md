# 3.22.0

Added
- Your agents can use your own browser. An agent in a reminal session on this computer can open tabs, read pages, take screenshots, click, type, press keys and scroll, in Chrome, Edge, Brave, Arc or Chromium, on macOS, Linux and Windows.
- It does what a browser automation tool does: hover, drag and drop, dropdowns, whole forms in one go, waiting for a page to load something, finding an element by words, the page's own dialogs, full page and single element screenshots, saving a page as a PDF, laying a page out at another size, dark mode, and reading what a tab downloaded.
- For debugging web apps it reads the page's console and its network requests.
- Several steps can go in one call, and the same tools work from a session's shell as `reminal browser <tool>`.
- After `reminal integrate` and loading reminal's extension once, agents in your reminal sessions on this computer can use this browser without asking. Switch it off, or stop one session, from the reminal button in the browser's toolbar.
- You always see it: each session works only in its own tab group, named with its id, a page shows a coloured border and a label while an agent is acting on it, and a notification with a Stop button appears when a session starts using the browser.
- It never types passwords or card numbers, and it stops at sign-in pages and CAPTCHAs and asks you to do those parts.
- Three things are off until you switch them on from the reminal button, because they reach further than clicking and typing: running scripts in pages (a script can act as you on any site you are signed in to), giving files from this computer to pages, and reading or changing cookies and site storage. The button's panel shows each time one was used, and on which site.
- It never uploads keys, password files or dotfiles, and never hands out the cookies, tokens or passwords your browser sends with a request.
- Everything stays on this computer: nothing about your browsing is sent anywhere by reminal.

Good to know
- To load the extension: open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the folder `~/.reminal/chrome-extension`. It is not in the Chrome Web Store yet.
- On Windows, `reminal integrate` sets it up for Chrome, Edge, Brave and Chromium. It was checked there with Edge.
