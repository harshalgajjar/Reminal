# 3.22.0

Added
- Your agents can use your own browser. An agent in a reminal session on this computer can open tabs, read pages, take screenshots, click, type, press keys and scroll, in Chrome, Edge, Brave, Arc or Chromium, on macOS and Linux.
- It asks you first, in the browser, for each session: Allow for this session, or Deny. Stop any session from the reminal button in the browser's toolbar.
- Each session works only in its own tab group, named after it, and a page shows a coloured border and a label while an agent is acting on it.
- It never types passwords or card numbers, and it stops at sign-in pages and CAPTCHAs and asks you to do those parts.
- Everything stays on this computer: nothing about your browsing is sent anywhere by reminal.

Good to know
- `reminal integrate` sets it up. Then load the extension once: open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick the folder `~/.reminal/chrome-extension`. It is not in the Chrome Web Store yet.
- Not on Windows yet.
