# 3.18.9

Added
- The session list says what an agent has set to run later (a loop, a reminder, a scheduled job), apart from what it is running now. A job due in six hours no longer looks like work in progress, and the count says when it was last read once it is old.
- Copilot CLI and Kilo Code CLI reopen on their own conversation when a session is restored, as the others do.
- Qwen Code's monitors and workflows are counted from its footer, beside its shells.
- The viewer keeps a short record of what shaped the screen (grid changes, sizes received, snapshots applied), copied from Settings, Size debug, for a bug report.

Fixed
- A notification from an agent no longer clears what its last turn said was still running in the background.
- Newer sign-in and limit screens are read: Qwen Code 0.26.9 (credits used up, signed out), Claude Code 2.1.319 (an organization whose usage is paused), Codex 0.167.0 (the device-code sign-in, an identity provider's lapse) and Droid 1.6.0 (no login). An agent's own sentence that happens to carry those words is not taken for one.
- Kilo Code's plugin is healed on start as the others are.
