# 3.21.2

Safety
- Voice now needs `reminal integrate` for every agent. It types what you say only into an agent it can tell is waiting for a message: one set up with `reminal integrate` that has reported in, and, for Claude Code, Qwen Code, Gemini CLI, OpenCode and Kilo, only while its input box is on screen. Elsewhere it says why and types nothing.
- Voice no longer types into Codex CLI or Amp, or into any agent not set up with `reminal integrate`: reminal cannot tell when they are waiting for you, and a question they ask on screen could have been answered by what you said.
- Voice never types while an agent is in shell mode, where Return would run the line as a command.
- Voice no longer types after something you had already started typing in the agent's box (a half-written message or a slash command): it says so, and you send or clear it first.
