# 3.14.13

- pi joins the agents `reminal integrate` sets up. A pi session now shows
  working, needs you, or done on your machines list like any other, so you
  can tell from your phone which one to go back to — and pi gets reminal's
  own tools, so from inside pi you can list your sessions, read what an
  agent on another machine is doing, and answer it.
- Nothing to download for it: `reminal integrate` installs everything pi
  needs, and `reminal integrate --remove` takes it away again.

Fixed
- A session running pi is now read as the agent it is. Before, asking
  another machine what a pi session was showing came back as unreadable
  fragments instead of the screen.
- The notes button in the Host panel sits on its own line, instead of
  crowding the version beside it.
