# 3.11.1

Fixed
- The state pill updates the instant it changes. When the agent in the session
  you're watching starts working, stops for you, or finishes, its pill in the
  session switcher flips right away, matching the notification you get, instead
  of trailing the fleet view's next refresh.
- A session that's asking you something shows "needs you", not "done". When an
  agent ends its turn on a question — a multiple-choice prompt, a yes/no, an
  approval — it reports the turn as finished, so the pill used to read "done"
  while it was actually waiting on your answer. reminal now notices the question
  still on screen and marks it "needs you" so it stands out.
- On Windows, agent state-reporting now sets up correctly when reminal lives in
  a path with a space in it. The hook command it wrote used a quoting style
  Windows doesn't accept, so the agents never reported their state; they do now.
