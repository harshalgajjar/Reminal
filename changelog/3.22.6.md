# 3.22.6

Improved
- `reminal integrate` fits your terminal: its text wraps on words to the width of the screen, a phone included, and no row is cut.
- It lists only the browsers you have, and ends on three short steps for loading the browser extension.
- Run at a terminal, it offers to open your browser's extensions page for you, waits for the extension to connect, and says when your browser is connected. On a Mac it also shows the `~/reminal-extension` folder in Finder.
- If the extension is already connected, it says so and skips the steps.
- `reminal integrate --check` and the browser tools now say plainly why the browser is not reachable and the one thing to do: not set up, the extension not loaded yet, no browser window open, reminal's daemon not running, or a reminal in the background from before an upgrade that is about to be replaced.
- A running agent is told when its tools change, for example when you set the browser up. Agents that listen for that pick the new tools up without a restart, and the restart line is shown only for the agents that still need one.
- `reminal integrate --check -v` shows where each browser's file is.
- `reminal daemon --install`, which installs and starts reminal's background service, is now listed in `reminal --help`.

Fixed
- Right after an upgrade, the first thing an agent asks of the browser no longer fails with advice to set the browser up again. It waits a few seconds for reminal's background service to come back, then goes through.
- A browser that is installed but has never been opened is now set up too.
- The text an agent reads from a page now includes an open dialog, first, under the line `Open dialog:`. Before, a dialog outside the page's main content was left out, so an agent did not know it was open.
- On a screen with two device pixels to a pixel, such as a Retina Mac, a screenshot is now the same size as the page, so a position read off the picture is where a click lands. Before, the picture was twice the size.
