# 3.13.3

Fixed
- The session switcher keeps itself current again, even before you open a
  session. Its state pills had stopped refreshing unless you were already
  connected to one, and a single unreachable machine could freeze the whole
  refresh — so the list you use to decide where to jump could sit on stale
  info. It updates on its own now, and one slow machine no longer holds up
  the rest.
