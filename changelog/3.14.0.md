# 3.14.0

Improved
- You can now start and stop sessions on your **other machines from the
  terminal**, not just the web app. `reminal new --machine <name>` opens a
  session on a machine you own (e.g. `reminal new --machine away`) and prints how
  to connect; `reminal kill` (or `stop`) `<session> --machine <name>` ends one there. Use the
  same name or `mach_` id you see in `reminal machines` — and tab-completion
  suggests your machines right after `--machine`.
