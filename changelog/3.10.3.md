# 3.10.3

Fixed
- Viewing a Linux desktop that runs Wayland no longer shows a black window.
  reminal now grabs the screen the way Wayland requires — through the desktop's
  own screenshot tool (grim, gnome-screenshot, or spectacle) — instead of the
  X11 method that came back blank there. If none of those tools is installed,
  you get a clear message about what to install (or to use an Xorg session)
  rather than a black screen. On Wayland, only the whole-desktop view works so
  far — per-window mirroring and remote mouse/keyboard control still need an
  Xorg session.
