# 3.7.1

New
- Tap a machine's CPU/memory in the Machines list to open its full vitals — CPU,
  memory, load, cores, and uptime — right there. Especially handy on a phone,
  where there's nothing to hover.

Fixes
- That vitals popover no longer gets cut off at the edge of the Machines list.
- Cleaned up the spacing between a machine's vitals and its session count.

For agents (MCP)
- The add_note tool now asks you to be precise about anything you point at on
  screen — a page or slide number, a tab or file name — so the note drops the
  user right on it.
