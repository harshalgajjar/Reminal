# 3.13.13

Fixed
- Starting a session on a Mac could fail with "detached reminal didn't report
  ready within 15s", leaving a session in your machines list that never
  connected. Reading the shell's folder name could hang, and it was holding up
  the session start behind it. It now gives up after a moment and the session
  starts regardless.
- Those hung lookups also kept running in the background afterwards, one per
  attempt, each using a whole CPU core and slowly making the Mac sluggish.
