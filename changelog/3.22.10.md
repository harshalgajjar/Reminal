# 3.22.10

Fixed
- Agents reading a page in your browser could get an empty page back after reminal was upgraded while the browser was closed. The browser had kept the older copy of reminal's extension and ran it on the newer files. The extension now notices this when the browser starts and reloads itself, with nothing for you to do.
- A browser already in that state is put right the same way, the next time it connects to reminal.
- If the extension's code cannot run in a page, the agent is now told so and what to do about it. It never gets an empty page as if the page had nothing on it.

Improved
- Every release is now checked by upgrading from the release before it in a real browser, then reading a page, taking a screenshot and clicking, before anything is published.
