# 3.13.22

Added
- Search boxes on Machines and Windows. Type a few letters to find the session
  or window you want instead of scrolling for it — a machine name keeps all of
  its sessions, a session name narrows to that one, and a card that was folded
  away opens itself when something inside it matches.
- The Apps search finally has the little clear button the other two have, so
  one tap gets you back to the whole list. It also tells you when nothing
  matches, rather than going quietly blank.

Fixed
- A background session now looks right the moment you open it. Some coding
  agents draw themselves to fit the terminal, and with nobody watching yet
  there was no size to fit — so Codex and the Antigravity CLI opened onto a
  blank screen. They come up properly now, and an agent reading one of these
  sessions gets clean text instead of jumbled fragments.
- A session no longer keeps saying "needs you" after you have already answered
  it. Replying to a question doesn't announce itself, so the mark could stick
  for the rest of a long turn on a session that was busy again. A session that
  really is waiting keeps its mark for as long as you need to get to it.
- Questions are recognised more reliably, so "needs you" lights up on the ones
  that are genuinely waiting on you and stays quiet on the ones that aren't.
