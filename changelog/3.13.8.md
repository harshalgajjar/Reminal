# 3.13.8

Improved
- When reminal updates itself, the AI agents connected to it now pick up the new
  version straight away on macOS and Linux — without restarting your editor or
  assistant, and without the connection dropping. Before this, an agent kept
  working from whatever version was current when it started, which could leave it
  convinced a reminal feature was missing when it had already shipped. On Windows
  it can't switch over in place, so instead the agent is told its list of reminal
  actions may be out of date, and how to refresh it.
- An agent that starts up holding an old list of reminal actions is now told so on
  its first use, rather than quietly working from it.
