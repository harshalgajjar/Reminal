# 3.10.0

New
- See which session needs you — at a glance. Every session now shows what its
  agent is doing: **working**, **needs you** (stopped for a question or a
  permission), or **done**. It's right there in `reminal list` and on the
  Machines screen, so across a whole fleet of agents you can tell which one to
  jump to without opening each session to check. Idle shells stay quiet.
- `reminal integrate` now also sets your coding agents up to report that state
  themselves — so it's exact, not guessed — in the same one command that wires
  in reminal's other features. Agents it can't set up are read straight from
  their screen instead, so this works with every agent either way.
