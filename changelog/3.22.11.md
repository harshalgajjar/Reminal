# 3.22.11

Fixed
- A Mac with many reminal sessions could run slow, with taps and typing in a viewer lagging. Every session measured the computer's CPU on its own, each time a viewer or a notice asked how the computer was doing, and on a Mac each measurement is costly. With dozens of sessions that added up to several processor cores spent on measuring.
- The CPU is now measured once for the whole computer, and every session reads that one value. While nobody is looking at the computer's state, nothing measures at all.

Improved
- `reminal machines` shows this Mac's CPU from the same shared measurement.
