# 3.20.3

Added
- The Host menu now shows a laptop's battery: how full it is, and how long it will last or how long until it is charged.

Fixed
- On Windows, programs in a session now see your own user name instead of the system account's.
- A session you close from the browser now stays closed after reminal restarts on that machine.
- If a session comes back after a restart without the agent it was running, it now shows the command that picks the conversation up again, instead of an empty prompt.
