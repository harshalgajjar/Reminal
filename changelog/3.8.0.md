# 3.8.0

New
- Attach to a session on the same computer even when that computer is offline.
  Running `reminal attach` (or `reminal connect`) to a session on this machine
  now reaches it directly, so it keeps working with no internet at all — on a
  plane, a locked-down network, or when the relay is unreachable. It picks this
  direct path automatically whenever the session is on the same machine, and
  falls back to the usual connection for everything else. Nothing about how it
  looks or feels changes — same PIN, same end-to-end encryption, same screen.
