# 3.18.3

Improved
- `reminal machines` shows each machine's id in full, the way `reminal machines rename` and `--machine` take it, and lists those commands under the machines.
- The id shown for this computer now works with `reminal machines rename`, `reminal new --machine` and `reminal kill --machine`.
- A machine name or id that matches nothing now lists the machines you can pick from, one per line.
